# OneTable

Лендинг платформы для покерных клубов (русский язык).

Дизайн сайта описан в `DESIGN.md` (направление «Light + Dark Felt»). Следуй ему; при конфликте с текущим `site.css` побеждает `DESIGN.md`, а если непонятно — спроси.
Все стили — в одном `site.css` (новые правила дописывай в конец). Работа идёт в ветке `redesign`, проверенные правки сразу пушатся и в `main` (он публикует сайт).
При любых задачах, связанных с дизайном, вёрсткой, UI/UX и визуальной полировкой (лендинг, кабинет `app/`, ТВ-дисплей, приложение игрока), по умолчанию использовать установленные дизайн-скиллы (`design-taste-frontend`, `impeccable`, `frontend-design`, `web-design-guidelines`) там, где они уместны.
После любых изменений интерфейса и вёрстки обязательно проводить быструю визуальную проверку до коммита, пуша и деплоя (не ограничиваться только `tsc` и `vite build`):
- для обычных UI-правок запускать локальный Playwright-чек `npm run check:ui` в `app/` (автоматически проверяет 1280×800 и 390×844, переполнения, ошибки консоли и сохраняет скриншоты в `app/.ui-check/`) или точечную проверку через плагин Chrome DevTools;
- полноценный проход браузерным субагентом использовать только для крупных новых экранов и сложных интерактивных сценариев, чтобы не тратить лишние токены.
