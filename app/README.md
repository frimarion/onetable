# OneTable

Рабочая локальная версия кабинета для покерных клубов. В кабинете используются Golos Text и фирменный знак OneTable. Переключатель с луной и солнцем меняет тему кабинета, расписания и ТВ; выбор сохраняется в браузере. В демо два клуба с отдельными турнирами, игроками и цветами ТВ.

## Запуск

Из папки `app` на Node.js 24:

```powershell
npm.cmd ci
npm.cmd run dev
```

Откройте [кабинет на 127.0.0.1:4180](http://127.0.0.1:4180/). Vite запускает React и локальный HTTP API. Встроенный PostgreSQL (PGlite) хранит данные в `.data/postgres`, в том числе между запусками. Можно выбрать отдельную базу через `ONETABLE_DATA_DIR`.

## Создание и публикация

1. В разделе «Турниры» выберите «Создать турнир». Задайте название, дату и время по Москве, описание для расписания и клубный или стандартный макет. Параметры, блайнды и перерывы можно изменить перед сохранением. Из сохранённого турнира настройки и структуру можно сохранить как новый клубный макет.
2. Нажмите «Сохранить черновик». Он появится в списке администратора и будет доступен для дальнейшего редактирования. Дату и время можно добавить позже.
3. Чтобы пропустить черновик, заполните дату и время и нажмите «Опубликовать сразу». У сохранённого черновика остаётся отдельная кнопка «Опубликовать». Из админки опубликованного турнира можно записывать игроков из CRM, открыть турнир, запустить таймер и вывести его на ТВ. Кнопка «Редактировать» сохраняет изменения в той же записи, включая после старта. Текущий и сыгранные уровни при этом закреплены.

«Создать неделю» копирует опубликованные турниры из выбранной недели в новую. Копии сохраняют день недели, время по Москве, настройки, блайнды и столы. В предварительном списке можно изменить название и время или исключить турнир. Выбранные турниры сохраняются черновиками или публикуются сразу. Игроки, оплаты, результаты и ход таймера остаются в исходном турнире.

В Doyle Poker доступны клубные макеты Daily Tournament, Deep Stack Tournament и Doyle's Final из локальных миграций Doyle. Deep Stack использует длительности из последней полной версии в SQL. Для финала исходное число 27 используется как лимит записи и вместимость трёх столов, а заявки создаются через запись игроков.

Расписание открывается по ссылке «Расписание клуба» в списке турниров. В карточке игрок записывается по имени, видит свой статус и может отменить запись до допуска к игре. Демо запоминает игрока в том же браузере. Проверенная клубная учётная запись и Telegram Mini App пока не подключены.

### Онлайн-запись и лист ожидания

- Лимит онлайн-записи задаётся в параметрах турнира. При включённой рассадке число записей ограничено количеством мест за столами и заданным лимитом. Значение 0 оставляет только ограничение по столам, а при отключённой рассадке запись безлимитна.
- Когда места заняты, новые игроки попадают в лист ожидания по времени записи. До старта администратор может подтвердить запись первого в очереди, когда появляется место.
- После старта администратор отмечает, кто из очереди пришёл. Когда появляется место, нажимает «Посадить» рядом с первым из пришедших, пока открыта поздняя регистрация. Сервер сразу начисляет вход и назначает свободное место. При отключённой рассадке кнопка «Допустить к игре» отмечает приход и начисляет вход. Уже допущенные игроки без места имеют приоритет при рассадке.

### Варианты аддона

В настройках турнира можно указать цену и число фишек для обычного, двойного и тройного аддонов. Двойной и тройной становятся доступны, когда для них задано число фишек. В строке пришедшего игрока кнопки «Аддон», «×2» и «×3» выбирают один вариант. Другой вариант заменяет начисление, повторное нажатие снимает аддон. Касса использует цену выбранного варианта, ТВ — выданные фишки.

### Структура блайндов

Уровни и перерывы можно перетаскивать за ручку слева или перемещать стрелками. «+ Перерыв» открывает выбор игрового уровня и длительности. После вставки фокус переходит к новому перерыву. Общая длительность показана над списком. Во время игры доступны для правок предстоящие уровни и перерывы.

Галочка «Анте» применяется ко всему турниру. Без неё анте скрыто в структуре и на таймере, а сохранённые суммы можно вернуть. При включении для редактируемых уровней с нулевым анте подставляется большой блайнд.

## Управление турниром

- **Турнир.** Запуск, пауза, переходы, корректировка времени, перерывы, структура блайндов и клубные шаблоны, стартовый стек, поздняя регистрация, аддон, PKO и ручные счётчики при отсутствии списка участников.
- **Игроки.** Запись из CRM, импорт имён, отметка прихода, аддоны, кнопки R− / R+ и возврат по реэнтри. При наличии ника он отображается первым, имя и фамилия идут в подписи. Поиск работает по обоим полям, ник можно указать при онлайн-записи или в карточке CRM. Вылетевшие переходят в конец списка игроков и поднимаются наверх в оплатах. У записи игрока, который не пришёл, есть кнопка отмены. Изменения видны в журнале турнира.
- **Рассадка.** В новом турнире выключена. Включается и отключается в настройках турнира. При отключении сохранённые назначения остаются в базе, а ТВ переходит с рассадки на таймер. Доступны настройка столов и вместимости, авторассадка свободных мест, жеребьёвка, балансировка, ручное назначение и обмен местами. Из карточки стола можно открыть планшет дилера. Для операций дилера, админа и ТВ данные обновляются из одной базы.
- **Оплаты и CRM.** В строке игрока видны суммы по способам оплаты. Можно принять весь остаток или записать отдельные суммы через «Частями», меняя способ для каждого платежа. Рассчитавшиеся игроки переходят вниз списка. В деталях доступны тарифы, льготы, погашение долгов прошлых турниров и история. Платёж можно отменить, исправить его способ или сбросить расчёт. Отчёт Excel содержит сводку по игрокам с итогами и отдельный лист операций.
- **Результаты и ТВ.** Места по порядку вылетов, расчёт призовой зоны, черновик поста для Telegram. На ТВ можно переключать таймер, рассадку, призовую зону и результаты, выводить сообщение и бонусную руку. Открытые кабинеты и экраны демо получают уведомления об изменениях сразу после сохранения. При разрыве связи кабинет периодически запрашивает состояние, а экран продолжает отсчёт по последнему подтверждённому состоянию.

Профили и данные в демо тестовые. По умолчанию доступны три стола по восемь мест и шаблон на шесть уровней. API слушает loopback. Рабочая авторизация Doyle, импорт регистраций Doyle и отправка постов в Telegram, кошелёк клубной карты Doyle, выгрузка в Google Sheets и пересчёт клубного рейтинга остаются отдельными интеграциями.

```powershell
npm.cmd test
npm.cmd run build
```

Сборка проверяет TypeScript и компилирует клиент. Для локальной работы клиента с API используйте `npm.cmd run dev`.

## Работа с телефона

В открытом турнире нижняя панель ведёт в список турниров, к игрокам, таймеру и оплатам. В «Ещё» доступны рассадка, настройки, результаты, журнал, редактирование, ТВ и CRM. В списке турниров и редакторе нижняя панель позволяет вернуться в текущий турнир или открыть CRM.
