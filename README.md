# OneTable

Сайт: https://frimarion.github.io/onetable/

Сайт платформы для покерных клубов: приложение для игроков под брендом клуба, настраиваемый таймер, админ-панель, CRM и инструменты для проведения турниров.

## Запуск

Сборка и установка зависимостей не требуются. Из корня проекта:

```sh
python3 -m http.server 4173
```

Откройте http://localhost:4173.

## Файлы

- `index.html` — структура и тексты сайта.
- `site.css` — все стили сайта (дизайн-система — в `DESIGN.md`).
- `app.js` — переключение демонстраций, выбор цвета, видео и просмотр скриншотов.
- Логотипы, скриншоты, персонажи ролей и видеопрезентация лежат в корне рядом с `index.html`.
- `hosting.json` — конфигурация размещения.

Сайт статический, пути к ресурсам относительные: корень репозитория можно выложить на любой статический хостинг (сейчас — GitHub Pages из `main`).

## Демонстрации и контакты

На сайте используются логотипы Doyle и Вятки, а также экраны главной мобильного приложения `tg-app.html` и панели игроков `admin.html`. Экраны подготовлены на демонстрационных данных без подключения к рабочей базе игроков.

Кнопки связи пока ведут к контактам Doyle Poker. Отдельного сервера приёма заявок нет; текст обращения можно скопировать в окне связи.

## Проверка JavaScript

```sh
node --check app.js
```

Исходники серверов клубов, рабочая база, ключи API и данные авторизации для запуска этого сайта не нужны и в проект не входят.
